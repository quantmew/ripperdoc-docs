Ripperdoc 可通过环境变量进行配置。模型与鉴权相关设置只读取 `RIPPERDOC_*`（不会读取 `OPENAI_API_KEY` 等提供商变量）。如果配置文件里已设置 `api_key`，可跳过 `RIPPERDOC_API_KEY`。

## RIPPERDOC_ 环境变量（会话覆盖）

这些变量会在当前会话中覆盖配置文件（不写入磁盘）。如果没有任何 profile，至少需要设置 `RIPPERDOC_MODEL`、`RIPPERDOC_PROTOCOL` 或 `RIPPERDOC_BASE_URL` 之一，才能构建模型配置。若未显式设置 `RIPPERDOC_PROTOCOL`，会根据 base URL 和/或模型名称自动推断。

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_BASE_URL` | API 基础 URL | - |
| `RIPPERDOC_API_KEY` | API 密钥 | - |
| `RIPPERDOC_AUTH_TOKEN` | Auth token（可替代 API key） | - |
| `RIPPERDOC_MODEL` | 模型名称（main 指针） | - |
| `RIPPERDOC_SMALL_FAST_MODEL` | 快速模型名称（quick 指针） | - |
| `RIPPERDOC_PROTOCOL` | 协议类型 | 自动检测 |

## 行为设置

### 超时与重试

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_API_TIMEOUT` | API 请求超时（秒） | `120` |
| `RIPPERDOC_MAX_RETRIES` | API 最大重试次数 | `10` |
| `RIPPERDOC_TOOL_TIMEOUT` | 单个工具执行超时（秒） | `300` |
| `RIPPERDOC_CONCURRENT_TOOL_TIMEOUT` | 并发工具批次总超时（秒） | `600` |

### 上下文与记忆

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_CONTEXT_TOKENS` | 上下文窗口大小限制 | 模型默认值 |
| `RIPPERDOC_AUTO_COMPACT` | 启用自动压缩 | `true` |
| `RIPPERDOC_MAX_QUERY_ITERATIONS` | 最大查询循环次数 | `1024` |
| `RIPPERDOC_MESSAGE_WARNING_THRESHOLD` | 警告的消息数阈值 | `500` |
| `RIPPERDOC_MESSAGE_CRITICAL_THRESHOLD` | 严重警告的消息数阈值 | `1000` |
| `RIPPERDOC_RESUME_REPLAY_MAX_MESSAGES` | 恢复会话时最大重放消息数（-1 全部，0 跳过） | `120` |

### 文件操作

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_FILE_CACHE_MAX_ENTRIES` | 最大文件缓存条目 | `500` |
| `RIPPERDOC_FILE_CACHE_MAX_MEMORY_MB` | 最大文件缓存内存（MB） | `50` |
| `RIPPERDOC_MAX_READ_FILE_SIZE_BYTES` | 允许读取的最大文件大小（字节） | `262144` |
| `RIPPERDOC_MAX_READ_LINES` | 未指定 limit 时最大可读行数 | `2000` |

### Bash 工具

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_BASH_TIMEOUT_MS` | 默认 bash 超时（毫秒） | `120000` |
| `RIPPERDOC_BASH_MAX_TIMEOUT_MS` | 最大 bash 超时（毫秒） | `600000` |
| `RIPPERDOC_BASH_MAX_OUTPUT_LENGTH` | 最大输出字符数 | `30000` |
| `RIPPERDOC_BASH_TASK_TTL_SEC` | 后台任务 TTL（秒） | `3600` |

### Shell 配置

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_SHELL` | 首选 shell | 自动检测 |
| `RIPPERDOC_SHELL_PATH` | shell 可执行文件路径 | 自动检测 |

### LSP 设置

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_LSP_TIMEOUT` | LSP 请求超时（秒） | `20` |

### MCP 设置

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_MCP_MAX_OUTPUT_TOKENS` | MCP 最大输出 token | `50000` |
| `RIPPERDOC_MCP_WARNING_TOKENS` | MCP 警告阈值 | `40000` |

## 代理设置

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_AGENT_RUN_TTL_SEC` | 代理运行 TTL（秒） | `3600` |

## 日志

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_LOG_LEVEL` | 日志级别（DEBUG、INFO、WARNING、ERROR） | `WARNING` |

## 开发

| 变量 | 说明 | 默认值 |
|----------|-------------|---------|
| `RIPPERDOC_DEBUG` | 启用调试模式 | `false` |
| `RIPPERDOC_DEV_MODE` | 启用开发模式 | `false` |

## .env 示例

```bash
# 模型覆盖（仅环境变量）
RIPPERDOC_BASE_URL=https://api.example.com/v1
RIPPERDOC_API_KEY=YOUR_API_KEY
RIPPERDOC_MODEL=gpt-4o-mini
RIPPERDOC_PROTOCOL=openai_compatible

# Timeouts
RIPPERDOC_API_TIMEOUT=180
RIPPERDOC_MAX_RETRIES=5

# Context
RIPPERDOC_CONTEXT_TOKENS=100000
RIPPERDOC_AUTO_COMPACT=true

# Bash settings
RIPPERDOC_BASH_TIMEOUT_MS=300000
RIPPERDOC_BASH_TASK_TTL_SEC=7200

# File settings
RIPPERDOC_MAX_READ_FILE_SIZE_BYTES=1048576
RIPPERDOC_MAX_READ_LINES=4000

# LSP settings
RIPPERDOC_LSP_TIMEOUT=30

# Logging
RIPPERDOC_LOG_LEVEL=WARNING
```

### 使用 RIPPERDOC_ 环境变量（内存配置）

```bash
# 使用自定义 API 端点
RIPPERDOC_BASE_URL=https://api.example.com/v1
RIPPERDOC_API_KEY=YOUR_API_KEY
RIPPERDOC_MODEL=gpt-4o-mini

# 或使用 Bearer token 认证
RIPPERDOC_BASE_URL=https://api.example.com/v1
RIPPERDOC_AUTH_TOKEN=YOUR_BEARER_TOKEN
RIPPERDOC_MODEL=gpt-4o-mini
RIPPERDOC_PROTOCOL=openai_compatible

# 指定不同的 quick 模型
RIPPERDOC_SMALL_FAST_MODEL=fast-model-name
```

## 加载环境变量

### 从 Shell 加载

```bash
export RIPPERDOC_BASE_URL="https://api.example.com/v1"
export RIPPERDOC_API_KEY="YOUR_API_KEY"
export RIPPERDOC_MODEL="gpt-4o-mini"
export RIPPERDOC_PROTOCOL="openai_compatible"
ripperdoc
```

### 从 .env 文件加载

在项目根目录创建 `.env` 文件：

```bash
RIPPERDOC_BASE_URL=https://api.example.com/v1
RIPPERDOC_API_KEY=YOUR_API_KEY
RIPPERDOC_MODEL=gpt-4o-mini
RIPPERDOC_PROTOCOL=openai_compatible
```

然后用 `direnv` 或手动 source：

```bash
source .env
ripperdoc
```

### 在 Python SDK 中使用

```python
import os
os.environ["RIPPERDOC_BASE_URL"] = "https://api.example.com/v1"
os.environ["RIPPERDOC_API_KEY"] = "YOUR_API_KEY"
os.environ["RIPPERDOC_MODEL"] = "gpt-4o-mini"
os.environ["RIPPERDOC_PROTOCOL"] = "openai_compatible"

from ripperdoc.sdk import query
```

## 安全提示

1. **不要提交 API key** 到版本控制
2. **使用 `.env.local`** 做本地覆盖（加入 `.gitignore`）
3. **若泄露要轮换 key**
4. **为不同环境使用不同 key**
